# TEMPLATE-0001

## Title
AI Research Report Output Template

## Purpose
This template defines the required output format for AI Scientist interpretation.

## Required Output Format

# 1. Results Summary

- 핵심 데이터 경향을 요약한다.
- 수치, 상관관계, figure를 근거로 작성한다.
- 과도한 해석은 피하고 관찰 결과를 먼저 정리한다.

# 2. Discussion

- 결과의 의미를 반도체 공정/소재 관점에서 해석한다.
- 공정 변수, 조성, 불순물, 전기특성 간 관계를 설명한다.
- 기존 literature 또는 mechanism knowledge와 연결한다.

# 3. Possible Mechanism

- 가능한 메커니즘을 2~3개 제시한다.
- 각 메커니즘의 근거와 한계를 함께 작성한다.

# 4. Limitations

- 현재 데이터만으로 확정할 수 없는 부분을 명확히 작성한다.
- 추가로 필요한 측정 또는 실험을 제안한다.

## Writing Rules

- 한국어 기술보고서 스타일로 작성한다.
- 근거와 가설을 구분한다.
- 없는 데이터를 만들어내지 않는다.
- 현재 데이터의 한계를 명확히 표시한다.
- 논문 Results/Discussion에 재사용 가능한 문장으로 작성한다.
