# SERA: Semiconductor Experimental Research Assistant

SERA is a prototype AI research assistant for semiconductor process development.

The current goal is to build a manual AI-assisted workflow:

Experiment Data  
→ Python Processing  
→ Data Profiling  
→ Research Planning  
→ Figure Generation  
→ Knowledge Retrieval  
→ Research Context Markdown  
→ ChatGPT Project Reasoning  
→ Report / Paper / PPT

## Current Version

v0.9 Knowledge Search Engine

## Features

- CSV data loading
- Experiment summary
- Correlation analysis
- Automatic plot generation
- Data profiling
- Research planning
- Knowledge base loading
- Knowledge search
- Research context markdown generation
